TD Engine — Feature Surface

14 production-ready modules. 348 tests. 98.6% pass rate. Same C++ source runs on Windows desktop and in any modern browser.

Scripting

  • tdscript VM — Custom Lua-like bytecode interpreter (3,075 lines). Lexer → parser → compiler → stack-based VM. Hot reload.
  • Visual Scripting — Node-based graph compiler. Generates tdscript source.

Networking

  • Reliable UDP Transport — Sliding-window ARQ, fragment reassembly, RPC system.
  • Server-Authoritative Netcode — Client prediction + rewind/replay, lag compensation.

Voxel

  • Greedy Mesher — 5-10x fewer triangles than naive meshing.
  • Worldgen — 4-octave simplex noise, trees, ores, water.
  • Lighting — Sunlight + BFS block light.
  • Streaming — Background-thread chunk loader with frustum culling.

UI Toolkit

  • 13 Widgets — Container, Label, Button, Slider, TextInput, ScrollView, ListView (10K items <1ms), Dropdown, Modal, Tooltip, Canvas.
  • Real Flexbox — justify-content, align-items, flex-grow/shrink/basis.

Animation + Audio

  • Skeletal Animation — Bone hierarchy, clips, cross-fade, 4-bone GPU skinning.
  • 3D Positional Audio — HRTF-lite panning, Schroeder reverb, Doppler.

Graphics

  • Visual Shader Graph — Node-based editor, GLSL codegen.
  • WebGPU Path — Backend selection + WGSL templates (Dawn/wgpu bindings TODO).

Platform

  • i18n — Locale fallback, plural forms, RTL detection.
  • Mobile/XR/Gamepad — Multi-touch + gestures, 6-DoF XR controllers, Standard Gamepad.
  • Plugin ABI — GDExtension-equivalent C ABI with hot reload.
  • Asset Catalog — Addressables-style async load + LRU eviction.
  • Archetype ECS — DOTS-style contiguous arrays per archetype.
